# COS 201 — Week 3 Practical

Variables, Data Types, Expressions and Input/Output (Java).

## Programs
- `SimpleCalculator.java` — reads two numbers; shows sum, difference, product, quotient and remainder.
- `AverageCalculator.java` — reads three scores; shows their sum and average.
- `ItemCost.java` — reads item name, unit price and quantity; shows subtotal, 7.5% VAT and total.

## Requirements
Java Development Kit (JDK) 8 or later.

## Compile
```
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## Run
```
java SimpleCalculator
java AverageCalculator
java ItemCost
```

## Sample run (ItemCost)
